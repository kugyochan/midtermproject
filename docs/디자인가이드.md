# Nextwatch v2 디자인 가이드

> 이 가이드에 있는 화면만 만듭니다(가이드에 없는 화면은 감점). 비즈니스 명칭은 README · 기획 · 셀프 논증 · 코드 주석에서 글자 하나 다르지 않게 씁니다.

## 1. 목적

Nextwatch v2의 모든 화면은 **"고르지 말고, 이유를 보고 결정하게"** 한다. 사용자가 무엇을 비교할지 고민하기 전에, 앱이 한 편과 그 이유를 먼저 보여 준다.

## 2. 원칙 세 가지

1. **결정이 먼저, 탐색은 나중.** 첫 화면은 목록이 아니라 한 편이다. (P08)
2. **숫자에는 이름과 뜻을 붙인다.** "92%"가 아니라 "내 취향 일치 92%", 누르면 뜻을 설명한다. (P02 · P10)
3. **기다림과 실패에는 말을 건다.** 로딩은 무엇을 하는 중인지, 오류는 원인과 "다시 시도"를. (P01 · P09)

| good / soso / bad | #7BD389 / #E0C36A / #E88A8A | 한 줄 평가 — 항상 아이콘 + 글자와 함께 (색만으로 구분하지 않음) |
| error | #FF8A80 | 오류 아이콘 |

- 글자: 작품 제목 26 굵게(headlineMedium) · 섹션 제목 16 · 본문 16(행간 1.5) · 보조 14
- 간격: 화면 가장자리 16 (넓은 화면 32) · 카드 안 16 · 요소 사이 8 / 12 / 20
- 누르는 곳: 결정 버튼 높이 56, 보조 버튼 48 이상
