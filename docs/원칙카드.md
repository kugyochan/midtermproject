## P08 — 미학적이고 미니멀한 디자인

- **원칙:** 지금 필요 없는 정보는 결정에 필요한 정보와 경쟁한다.
- **근거:** 키노라이츠 홈은 랭킹 · 신작 · 종료 예정 · 배너가 함께 나와, 사용자는 목록을 넘기다 지친다. #15 "신호등 평가 순은 특히 최근에 …"(평가순 탐색으로는 고르기 어렵다), 저니 2–3단계 감정 −1 → −2.
- **적용:** A 오늘의 한 편 — A-3 추천 카드(한 편) · A-4 추천 이유 칩 3개 · A-5 결정 버튼만 강조. `a_today_pick_screen.dart`, `common.dart ReasonChips // P08`
- **시연:** [a_home.png](images/a_home.png) (전: [before_home.png](images/before_home.png))
- **판단:** 고려한 대안 "후보 5~10개 가로 목록" → v1의 탐색 문제를 되돌림(쟁점 1). "AI 설명 문단" → 결정 버튼을 밀어냄(쟁점 2).

## P09 — 오류 인식 · 진단 · 복구 돕기

- **원칙:** 오류는 쉬운 말로, 원인과 해결 방법을 함께.
- **근거:** #12 "반응 개느림. 뭐하나 터치해서 넘어가고 볼라면 한참 기달려야되고" — 느리거나 실패할 때 아무 안내가 없다.
- **적용:** 공통 ErrorView — 아이콘 → "추천을 불러오지 못했어요" → 원인 한 줄 → 다시 시도(같은 화면을 새로 열어 GET). `state_views.dart // P09`
